🔹 1. Interpolation {{ }} → afficher une valeur
📌 Utilisation :Quand tu veux afficher une donnée dans le HTML

Exemple :
<h1>{{ titre }}</h1>
<p>{{ user.name }}</p>
👉 Cas typiques :
afficher un texte
afficher une variable
afficher un résultat

🔹 2. Property Binding [ ] → modifier un attribut HTML
📌 Utilisation :Quand tu veux donner une valeur à une propriété HTML

Exemple :
<img [src]="imageUrl">
<button [disabled]="isDisabled">OK</button>
👉 Cas typiques :
image (src)
disable button
class dynamique
style dynamique

🔹 3. Event Binding ( ) → écouter une action utilisateur
📌 Utilisation :

Quand tu veux réagir à un événement

Exemple :
<button (click)="onClick()">Clique moi</button>
<input (keyup)="onKeyUp()">
👉 Cas typiques :
clic
saisie clavier
souris
submit formulaire

🔹 4. Two-way Binding [( )] → synchronisation automatique
📌 Utilisation :

Quand tu veux lier HTML + variable en même temps

Exemple :
<input [(ngModel)]="nom">
<p>{{ nom }}</p>
👉 Cas typiques :
formulaires
input utilisateur
champs de saisie



Un composant Angular, c’est le bloc principal de construction d’une application Angular.

🔹 C’est quoi un composant ?

Un composant = une partie de l’interface utilisateur (UI) + sa logique.

👉 Exemple :

un header (menu)
une page login
une liste de produits
un bouton avec comportement
🔹 Rôle d’un composant
1. 🖼️ Gérer l’affichage (HTML)

Le composant contrôle ce que l’utilisateur voit.

<h1>Bienvenue</h1>
2. 🧠 Gérer la logique (TypeScript)

Il contient les variables et fonctions.

titre = "Accueil";

onClick() {
  console.log("cliqué");
}
3. 🔄 Relier HTML + logique

Il connecte le HTML et le TypeScript.

<h1>{{ titre }}</h1>
<button (click)="onClick()">OK</button>
4. 🧩 Réutilisabilité

Un composant peut être utilisé plusieurs fois.

Exemple :

<app-navbar>
<app-card>
<app-footer>
🔹 Structure d’un composant

Chaque composant Angular a 3 fichiers :

component.ts   → logique
component.html → interface
component.css  → style
🔹 Résumé simple

👉 Un composant sert à :

afficher une partie de la page
gérer sa logique
être réutilisé

👉 Composant = une brique LEGO
👉 Application = assemblage de toutes les briques

3. Two-way Binding
Syntaxe : [(ngModel)]="variable"

⚡ Résumé rapide :
Type	Syntaxe	Sens
Interpolation	{{ }}	TS → HTML(Les accolades {})
Property binding	[ ]	TS → HTML([] s’appelle des crochets)
Event binding	( )	HTML → TS
Two-way binding [( )]↔ (les deux)

ANGULAR - SYNTAXE PRINCIPALE

{{ }}   → Interpolation
          (afficher une donnée TS dans HTML {{ }} → afficher)
          ex: {{ nom }}

[ ]     → Property Binding
          (lier une propriété HTML  [ ] → envoyer une valeur vers le HTML)
          ex: [src]="imageUrl"

( )     → Event Binding
          (réagir à un événement ( ) → écouter un événement)
          ex: (click)="fonction()"

[( )]   → Two-way Binding
          (liaison dans les deux sens  [( )] → les deux en même temps)
          ex: [(ngModel)]="nom"

------------------------------------------------

AUTRES SYMBOLES

{ }     → Objet JavaScript
ex: { nom: "Ali" }

[ ]     → Tableau JavaScript
 ex: [1, 2, 3]

 🧠 Astuce pour mémoriser :
{{ }} → afficher
[ ] → envoyer une valeur vers le HTML
( ) → écouter un événement
